# ADR-0004 · WhatsApp integration and number ownership

**Status** [PROPOSAL] Pending review · **Date** 18 November 2026 WIB

[Parent RFC](../rfc/RFC-0001-MERAJUT-RECONSTRUCTION.md)

## Decision

Use one Merajut-managed number and official Meta Cloud API behind an adapter. Switch to an approved BSP if it provides better provisioned access and verifiable data handling. Keep provider coordination in the dashboard. Use a labeled simulator until approval and delivery are demonstrated.

## Alternatives

Per-tailor numbers multiply onboarding and webhook routing. Direct relay adds policy and privacy complexity. Web-only is the release fallback if official access is unavailable.

## Consequences and verification

One identity and support/handoff path. Adapter fixtures exercise the same commands. Capture actual provider responses and receipts before claiming live integration.

## Owners and open decisions

Integration owner · Verify WABA/number, app ownership, test vs production permissions, templates, support process and costs.
